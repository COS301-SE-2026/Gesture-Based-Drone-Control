  <h1>Fly a drone with <em>nothing but your hands</em></h1>
  <p class="tx-hero__sub">
    A real-time computer-vision system that eliminates the physical controller entirely. Hand gestures detected through a live camera feed, classified by a dual rule-based and ML engine, translated directly into drone flight commands, with safety fail-safes built in from the ground up. A droneSim is provided side-by-side to test out the different features in a virtual environment to get a feel of the entire application. We offer a wide range of accessibility options if you would like to switch it up and go back to using controller/keyboard/UI interface inputs instead of hand gestures.
  </p>

    <div class="tx-card__label">Real-Time Pipeline</div>
    <h3>Millisecond Latency</h3>
    <p>Live camera → gesture classification → command translation → drone. FastAPI WebSocket backend.</p>
  </div>
  <div class="tx-card">
    <div class="tx-card__label">Safety First</div>
    <h3>Built-In Fail-Safes</h3>
    <p>Hover on tracking loss, emergency stop gesture, idle detection auto-land, active by default.</p>
